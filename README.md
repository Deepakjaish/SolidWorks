# 🚀 SolidWorks Projects

Welcome to my **SolidWorks Projects** repository! This repository contains my CAD designs, 3D models, engineering drawings, and practice projects created using **SolidWorks**.

## 📌 About

The purpose of this repository is to:

* Improve my CAD and mechanical design skills.
* Document my learning journey with SolidWorks.
* Showcase personal and academic projects.
* Maintain version-controlled backups of my designs.

## 🛠️ Software Used

* SolidWorks
* SolidWorks Simulation (where applicable)
* SolidWorks Drawings

| `.IGES` / `.IGS` | IGES Exchange Files  |
| `.STL`           | 3D Printing Files    |
